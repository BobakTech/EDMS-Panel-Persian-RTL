# PMIS Project Overview

## معرفی
PMIS یک سیستم مدیریت اطلاعات پروژه است که سال‌ها توسعه داده شده و دارای بخش‌های متعدد مدیریتی، فایل، تصویر، دوربین و ارتباطات لحظه‌ای است.
اطلاعات پیشرفت پروژه ها  و محاسبات پیشرفت و گانت تحت وب بومی و محاسبات صورت وضعیت و تعدیل و گزارشات کارگاهی

## تکنولوژی‌ها

- PHP (5.3، 5.6، 7.4، PHP 8)
- MySQL 5.7
- Apache روی Windows
- ADODB
- JavaScript


# Mobile Application

بررسی شده:

- React.js
- React Native


هدف:

ایجاد نسخه موبایل PMIS.



## قوانین توسعه

- سیستم Legacy است.
- سازگاری با نسخه‌های قدیمی PHP مهم است.
- Performance و Memory باید همیشه بررسی شود.
- راهکار عملی نسبت به راهکار تئوری اولویت دارد.
- قبل از تغییر معماری، محدودیت‌های سیستم فعلی بررسی شود.


# Coding Rules

هنگام پاسخ:

1. کد کامل ارائه شود.
2. نسخه PHP مشخص شود.
3. Performance بررسی شود.
4. راهکار سازگار با Legacy ارائه شود.
5. تغییرات بزرگ بدون بررسی پیشنهاد نشود.
